# Recall

goofy ahh cards that are better than quizlet

Open index.html to use the app. Decks are saved in this browser, so keep an exported backup if you want another copy.

You can create decks, edit cards, study, retry missed cards, shuffle, search, and import or export backups.

Run node tests/check.cjs to check the data and study helpers. Use Space to reveal an answer, then 1 for correct or 2 for missed.
