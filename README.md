# Recall

Recall is a goofy flashcard app where you can add your own decks, edit your cards, and then study them. You can shuffle, retry cards you missed, search cards, and also import/export backups. Decks are saved in your browser.

## Languages and Libs
HTML, CSS, and Javascript. I didn't use any external libraries or anything. 

## How to Run It
Download or clone the repo, and then just open index.html lol
There are also tests I added that you can run from node.js by running "node tests/check.cjs"
